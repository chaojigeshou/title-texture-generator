# 镜中都市 · 称号贴图生成器

在浏览器里制作游戏称号贴图。可组合背景、底板、边框、徽记、字材、装饰和动画，统一生成一系列称号素材。绘制和导出都在本地完成。

## 使用方法

1. 下载仓库并解压，双击打开 [称号生成器_单文件.html](称号生成器_单文件.html)。也可直接打开完整目录中的 [index.html](index.html)。
2. 选一套模板，在「文案主题」编辑自己的称号，再到「模块」调整样式。用画布下方的时间轴预览动画。
3. 在「输出」导出 PNG、GIF 或方形图标。在「素材工坊」可制作带帧坐标和时长清单的动画精灵图，也可用逐行文本或 TSV 批量导出，每批最多 32 条。

公开版包括 43 套视觉模板、139 个绘制模块、9 条原创示例称号和自定义系列。支持自动草稿、收藏和 JSON 配置导入导出。精灵图的 JSON 帧清单可由游戏或引擎读取。

## 修改与打包

页面入口为 `index.html`，Canvas 绘制、编辑状态及导出功能位于 `模块/`。修改源码后，在项目目录运行：

```shell
node _tools/bundle.mjs
```

此命令重新生成离线单文件版。日常打开和使用页面无需安装 Node.js。
